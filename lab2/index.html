Lab 2: Data Logger & Power Measurement

Home | Lab 1 | Lab 2

What this lab does

Build a smart environmental/activity data logger: sample IMU + temperature, timestamp using RTC, and compare power in two modes (Mode 1: no SD writes vs Mode 2: SD logging).

Operating Modes (Control via BLE)

Step 0 — nRF BLE LED Test (Proof)

Using the BLE app, I write a value to the board: 1 turns Green LED ON, and 0 turns Red LED ON.

Code (opens on my GitHub page, not download): LEDNRF.ino

Mode 1 — Sample Only (No SD Writes)

  • Sample IMU + temperature at fixed frequency (example: 100 Hz)
  • RTC timestamp is included
  • OLED/serial indicates Mode 1
  • No SD card logging (lower power)

Mode 2 — Sample + SD Logging

  • Same sampling frequency + RTC timestamp
  • Data is written to SD card
  • OLED/serial indicates Mode 2

Code (opens on my GitHub page): MODE1_AND_MODE2.ino

Lab 2 Questions / Requirements

  • Data Format: hr,min,sec,ax,ay,az,gx,gy,gz,temp
  • Power Measurement: Measure average current for each mode (60–120 seconds), record Vusb and Iavg, compute Pusb = Vusb × Iavg
  • Battery Runtime Estimate: 500 mAh @ 3.7V, efficiency = 0.85
    Ibatt ≈ Pusb / (3.7 × 0.85)
    Runtime (hours) ≈ 0.5 / Ibatt
  • Logging Overhead: ΔI and ΔP between Mode 2 and Mode 1

USB Power Meter (Setup Proof)

I connected a USB digital tester to measure voltage/current during Mode 1 and Mode 2.
