This lab focuses on sampling IMU and temperature data, logging with RTC timestamps, and comparing power consumption with and without SD card logging.

Operating Modes (Required)

  • Mode 1 (No SD Logging): Sample IMU + temperature at fixed frequency (e.g., 100 Hz), RTC timestamp, OLED shows mode.
  • Mode 2 (SD Logging Enabled): Same sampling frequency, RTC timestamp, data written to SD card, OLED shows mode.
  • Data Format: hr,min,sec,ax,ay,az,gx,gy,gz,temp

Code (GitHub Links)

  • BLE LED Test (Write 1 / 0): LEDNRF.ino

Measured Values

Mode 1 (Sample Only)

  • Current (A): 0.024, 0.028, 0.032
  • Voltage (V): 5.105, 5.097, 5.080

Mode 2 (Sample + SD Logging)

  • Current (A): 0.044, 0.048, 0.052
  • Voltage (V): 5.105, 5.097, 5.080

Calculations (Required)

1) Average USB Voltage

Vusb,avg = (5.105 + 5.097 + 5.080) / 3 = 5.094 V

2) Average USB Current

Mode 1: Iusb,avg = (0.024 + 0.028 + 0.032) / 3 = 0.028 A (28 mA)
Mode 2: Iusb,avg = (0.044 + 0.048 + 0.052) / 3 = 0.048 A (48 mA)

3) USB Power

Pusb = Vusb,avg × Iusb,avg
Mode 1: 5.094 × 0.028 = 0.143 W
Mode 2: 5.094 × 0.048 = 0.245 W

4) Battery Current Estimate

Battery: 500 mAh @ 3.7 V, efficiency η = 0.85
Ibatt ≈ Pusb / (3.7 × 0.85) = Pusb / 3.145
Mode 1: 0.1426 / 3.145 = 0.04535 A (45.35 mA)
Mode 2: 0.2445 / 3.145 = 0.07775 A (77.75 mA)

5) Runtime Estimate

Runtime (hours) ≈ 0.5 / Ibatt(A)
Mode 1: 0.5 / 0.04535 = 11.02 hours
Mode 2: 0.5 / 0.07775 = 6.43 hours

6) SD Logging Overhead

ΔI = 0.048 − 0.028 = 0.020 A (20 mA)
ΔP = 0.245 − 0.143 = 0.102 W (102 mW)

Final Results Table

Mode Vusb_avg (V) Iusb_avg (mA) Pusb_avg (W) Ibatt (mA) Runtime (hours)
Mode 1 (Sample Only) 5.094 28 0.143 45.35 11.02
Mode 2 (Sample + Log) 5.094 48 0.245 77.75 6.43
Overhead (Mode2 − Mode1) — +20 +0.102 +32.40 4.59

Short Discussion

Mode 2 draws higher average current and shows larger fluctuations because SD card write/flush operations happen in bursts. Compared to Mode 1, SD logging increases average USB current by 20 mA and average power by ~0.102 W, increasing estimated battery current from 45.35 mA to 77.75 mA. As a result, estimated runtime drops from ~11.0 h to ~6.4 h.
