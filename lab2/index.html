This lab focuses on sampling IMU + temperature data, logging with RTC timestamps, and comparing power consumption with and without SD card logging.

Modes:
  • Mode 1 (No SD Logging): Sample IMU + temperature at fixed frequency (e.g., 100 Hz), RTC timestamp, OLED shows mode.
  • Mode 2 (SD Logging Enabled): Same sampling frequency, RTC timestamp, data written to SD card, OLED shows mode.
Data format: hr,min,sec,ax,ay,az,gx,gy,gz,temp

Power Measurement Results & Calculations

Raw Readings

  • Mode 1 (Sample Only) — Current (A): 0.024, 0.028, 0.032; Voltage (V): 5.105, 5.097, 5.080
  • Mode 2 (SD Logging) — Current (A): 0.044, 0.048, 0.052; Voltage (V): 5.105, 5.097, 5.080

Averages

  • Average USB voltage: Vusb,avg = (5.105 + 5.097 + 5.080) / 3 = 5.094 V
  • Mode 1 average current: Iusb,avg(M1) = (0.024 + 0.028 + 0.032) / 3 = 0.028 A = 28 mA
  • Mode 2 average current: Iusb,avg(M2) = (0.044 + 0.048 + 0.052) / 3 = 0.048 A = 48 mA

USB Power

  • Mode 1: Pusb(M1) = 5.094 × 0.028 = 0.1426 W ≈ 0.143 W
  • Mode 2: Pusb(M2) = 5.094 × 0.048 = 0.2445 W ≈ 0.245 W

Battery Runtime Estimate (500 mAh @ 3.7V, η = 0.85)

Lab sheet formulas:
Ibatt ≈ Pusb / (3.7 × 0.85)
Runtime (hours) ≈ 0.5 / Ibatt

  • Denominator: 3.7 × 0.85 = 3.145
  • Mode 1: Ibatt(M1) = 0.1426 / 3.145 = 0.04535 A = 45.35 mA
  • Mode 2: Ibatt(M2) = 0.2445 / 3.145 = 0.07775 A = 77.75 mA
  • Mode 1 runtime: t(M1) = 0.5 / 0.04535 = 11.02 hours
  • Mode 2 runtime: t(M2) = 0.5 / 0.07775 = 6.43 hours

Summary Table

Mode Vusb,avg (V) Iusb,avg (mA) Pusb,avg (W) Ibatt (mA) Runtime (hours)
Mode 1 (Sample Only) 5.094 28 0.143 45.35 11.02
Mode 2 (Sample + SD Logging) 5.094 48 0.245 77.75 6.43
Overhead (Mode2 − Mode1) — +20 +0.102 +32.40 −4.59

Interpretation (for report)

Mode 2 draws higher average current and shows larger fluctuations because SD card write/flush operations are bursty. Compared to Mode 1, logging increases average USB current by 20 mA and USB power by ~0.102 W, increasing estimated battery current from 45.35 mA to 77.75 mA. As a result, estimated runtime drops from ~11.0 h to ~6.4 h (about 4.6 hours less, ~42% reduction).
