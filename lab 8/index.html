Overview

This page documents my work for Lab 8: PWM-Based Motor Speed Control and ADC Temperature Measurement. In this lab, I used PWM to control the speed of a DC motor and interfaced an analog temperature sensor with the ESP32-S3 using an ADC pin. I also used switches to adjust the PWM duty cycle and observe real-time motor behavior.

The videos below show the motor demonstration and the oscilloscope waveform observation.

Lab 8 Workflow

  • Connected the switches to the ESP32-S3 board.
  • Generated a PWM signal for motor speed control.
  • Connected the DC motor using the required driver circuit.
  • Used button inputs to change the PWM duty cycle.
  • Observed motor speed changes in real time.
  • Interfaced the analog temperature sensor to an ADC pin.
  • Read the analog sensor value and converted it to voltage.
  • Verified the PWM waveform using the oscilloscope.
