Build a smart environmental/activity data logger: sample IMU + temperature, timestamp using RTC, and compare power in two modes (no SD vs SD logging).

What this lab does

  • Samples IMU (accel + gyro) and temperature
  • Reads RTC time for timestamp
  • Compares power consumption for: Mode 1 (no SD writes) vs Mode 2 (SD logging)
  • Stores data to SD in CSV format

Lab 2 Questions / Requirements

Mode 1 — Sample Only (No SD Writes)

  • Sample IMU + temperature at fixed frequency (e.g., 100 Hz)
  • RTC timestamp
  • OLED shows current mode
  • No SD card writes

Mode 2 — SD Logging Enabled

  • Same sampling frequency
  • RTC timestamp
  • Data written to SD card
  • OLED shows current mode

Power Measurement

  • Measure average current for each mode (60–120 seconds)
  • Record Vusb and Iavg
  • Compute Pusb = Vusb × Iavg

Battery Runtime Estimate

500 mAh @ 3.7V, efficiency = 0.85
Ibatt ≈ Pusb / (3.7 × 0.85)
Runtime (hours) ≈ 0.5 / Ibatt

Logging Overhead

  • Compute ΔI and ΔP between SD logging and no logging

Data Format (CSV)

hr,min,sec,ax,ay,az,gx,gy,gz,temp
