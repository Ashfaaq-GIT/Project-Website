Overview

This page documents my work for Lab 6: Finite State Machine and Object Detection. In this lab, I first tested the ESP32S3 built-in LED and camera capture system. After that, I created the Edge Impulse project, uploaded and labeled the dataset, generated features, configured the model, trained the FOMO object detection model, and checked the final detection result.

The vision part of Lab 6 has been completed successfully. The screenshots below show the step-by-step progress in the same order as the lab workflow.
