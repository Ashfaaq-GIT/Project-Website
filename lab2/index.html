Lab 2 Questions / Requirements

  • Mode 1 (No SD Logging): Sample IMU + temperature at fixed frequency (e.g., 100 Hz), RTC timestamp, OLED shows mode.
  • Mode 2 (SD Logging Enabled): Same sampling frequency, RTC timestamp, data written to SD card, OLED shows mode.
  • Power Measurement: Measure average current for each mode (60–120 seconds), record Vusb and Iavg, compute Pusb = Vusb × Iavg.
  • Battery Runtime Estimate: 500 mAh @ 3.7V, efficiency = 0.85
    Ibatt ≈ Pusb / (3.7 × 0.85)
    Runtime (hours) ≈ 0.5 / Ibatt
  • Logging Overhead: ΔI and ΔP between SD logging and no logging.
  • Data Format: hr,min,sec,ax,ay,az,gx,gy,gz,temp
