Lab 2: Data Logger & Power Measurement

← Back to Home

What this lab does

Build a smart environmental/activity data logger: sample IMU + temperature, timestamp using RTC, and compare power in two modes (no SD vs SD logging).

Lab 2 Questions / Requirements

Mode 1 — Sample Only (No SD Writes)

  • Sample IMU + temperature at a fixed sampling frequency (example: 100 Hz).
  • Timestamp each record using the RTC.
  • No SD card writes.
  • OLED shows Mode + frequency.

Mode 2 — Sample + Log (SD Logging Enabled)

  • Same IMU + temperature sampling frequency as Mode 1.
  • Timestamp each record using the RTC.
  • Write data to SD card (CSV or TXT).
  • OLED shows Mode + frequency.

Power Measurements

  • Measure average current for each mode (run each mode 60–120 seconds).
  • Record: Vusb and Iavg
  • Compute: Pusb = Vusb × Iavg

Battery Runtime Estimate (500 mAh @ 3.7V, η = 0.85)

  • Ibatt ≈ Pusb / (3.7 × 0.85)
  • t(hours) ≈ 0.5 / Ibatt
  • Logging overhead: ΔI and ΔP

Required data format

Each record must include timestamp + IMU accel + IMU gyro + temperature.

hr,min,sec,ax,ay,az,gx,gy,gz,temp
