Lab 7 - 4-Key Digital Piano using Sine Wave Output

In this lab, I built a 4-key digital piano using sine wave generation and a simulated 4-bit DAC. The design uses 4 GPIO pins for DAC output and 4 buttons as piano keys. Each key plays a different musical note: C, D, E, and G. :contentReference[oaicite:3]{index=3}

Objective

The goal of this lab was to generate sine waves corresponding to musical notes and create a small digital piano. The DAC output uses 16 levels from 0 to 15, and the waveform is controlled using a timer. :contentReference[oaicite:4]{index=4}

Implementation Summary

  • Used 4 GPIO pins to simulate a 4-bit DAC.
  • Used a 16-step sine lookup table for waveform generation.
  • Connected 4 push buttons for the notes C, D, E, and G.
  • Adjusted the timer period for each note frequency.
  • Displayed waveform behavior using an oscilloscope.

Notes and Timer Periods

  • Key 0 - C - 523.251 Hz - 120 us
  • Key 1 - D - 587.330 Hz - 106 us
  • Key 2 - E - 659.255 Hz - 95 us
  • Key 3 - G - 783.991 Hz - 80 us

Wiring and Hardware

The circuit was built using the Xiao ESP32-S3, resistors, push buttons, speaker or buzzer, and oscilloscope. The DAC was implemented using a binary-weighted resistor network connected to 4 GPIO pins. :contentReference[oaicite:5]{index=5}

Code Logic

The DAC output function writes a 4-bit value across the DAC pins. In the main loop, button states are checked continuously. When a key is pressed, the waveform is activated and the timer period is changed to match the required note. If no key is pressed, the waveform is stopped and DAC output is cleared. :contentReference[oaicite:6]{index=6}

Conclusion

This lab demonstrated how a microcontroller can generate different audio tones using timer-based sine wave output and a simple DAC built from GPIO pins and resistors. By assigning different frequencies to each key, the system worked like a small digital piano.
