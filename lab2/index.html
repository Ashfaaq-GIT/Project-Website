This lab focuses on sampling IMU and temperature data, logging with RTC timestamps, and comparing power consumption with and without SD card logging.

Operating Modes (Required)

  • Mode 1 (No SD Logging): Sample IMU + temperature at fixed frequency (e.g., 100 Hz), RTC timestamp, OLED shows mode.
  • Mode 2 (SD Logging Enabled): Same sampling frequency, RTC timestamp, data written to SD card, OLED shows mode.
  • Data Format: hr,min,sec,ax,ay,az,gx,gy,gz,temp

Power Measurement Results & Calculations

Raw Measurements

Mode 1 (Sample only / No SD Logging)

  • Current (A): 0.024, 0.028, 0.032
  • Voltage (V): 5.105, 5.097, 5.080

Mode 2 (Sample + SD logging)

  • Current (A): 0.044, 0.048, 0.052
  • Voltage (V): 5.105, 5.097, 5.080

Averages

  • Average USB voltage (both modes): (5.105 + 5.097 + 5.080) / 3 = 5.094 V
  • Mode 1 average current: (0.024 + 0.028 + 0.032) / 3 = 0.028 A (28 mA)
  • Mode 2 average current: (0.044 + 0.048 + 0.052) / 3 = 0.048 A (48 mA)

USB Power

  • Mode 1: Pusb = 5.094 × 0.028 = 0.143 W
  • Mode 2: Pusb = 5.094 × 0.048 = 0.245 W

Battery Current Estimate (500 mAh @ 3.7V, η = 0.85)

Ibatt ≈ Pusb / (3.7 × 0.85) → denominator = 3.145

  • Mode 1: 0.1426 / 3.145 = 0.04535 A (45.35 mA)
  • Mode 2: 0.2445 / 3.145 = 0.07775 A (77.75 mA)

Runtime (hours) ≈ 0.5 / Ibatt(A)

  • Mode 1 runtime: 0.5 / 0.04535 = 11.02 hours
  • Mode 2 runtime: 0.5 / 0.07775 = 6.43 hours

SD Logging Overhead (Mode2 − Mode1)

  • ΔI = 0.048 − 0.028 = 0.020 A (20 mA)
  • ΔP = 0.245 − 0.143 = 0.102 W
  • Δt = 6.43 − 11.02 = −4.59 hours

Final Results Table

Mode Vusb_avg (V) Iusb_avg (mA) Pusb_avg (W) Ibatt (mA) Runtime (hours)
Mode 1 (Sample Only) 5.094 28 0.143 45.35 11.02
Mode 2 (Sample + SD Log) 5.094 48 0.245 77.75 6.43
Overhead (Mode2 − Mode1) — +20 +0.102 +32.40 −4.59

Discussion

Mode 2 draws higher average current and shows larger fluctuations because SD card write/flush operations are bursty. Compared to Mode 1, SD logging increases average USB current by 20 mA and average USB power by ~0.102 W. Using the lab battery model (500 mAh @ 3.7 V, 85% efficiency), the estimated battery current increases from 45.35 mA (Mode 1) to 77.75 mA (Mode 2), reducing estimated runtime from ~11.0 hours to ~6.4 hours.
